JavaScript Variable Scope?

=> Variable Scope determines where a variable can be accessed in a JavaScript program.

types of variable scope in JavaScript:

Global Scope
Function Scope
Block Scope

Global Scope

A variable declared outside any function or block has global scope.

=> Accessible from anywhere in the program. Can be accessed inside functions and blocks.

Function Scope

=> Variables declared using var inside a function are only accessible inside that function

Block Scope

=> Variables declared with let and const are block scoped.
=> A block is anything inside { }.

Lexical Scope

=> A child function can access variables from its parent function.

| Feature        | var   | let    | const |
| -------------- | ---   | ---    | ----- |
| Global Scope   | ✅   | ✅   | ✅     |
| Function Scope | ✅   | ❌   | ❌     |
| Block Scope    | ❌   | ✅   | ✅     |

    }

Summary
Scope	                   Declared Where	                                Accessible Where
Global	               Outside all functions/blocks	                           Everywhere
Function	                Inside a function (var)                     	Only inside that function
Block	                Inside {} using let or const	                      Only inside that block
Lexical	                    Nested functions	                   Child functions can access parent variables
